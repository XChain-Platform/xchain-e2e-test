xchain-e2e-test dead-code sweep
===============================

Candidates are src/ files that no package entry or node-run npm script reaches
through a literal require or import.

A reference is counted only when it names the file: inside xchain-e2e-test a relative
require, import or mock specifier that resolves to the file (with or without .js, or as
a directory index); in every other repository and in the platform claude/ directory a
path that contains xchain-e2e-test/<file path>. A bare substring of a file name is not
a reference. Counts are taken from git at the pinned revisions; claude counts the
tracked platform claude/ directory.

Every candidate has at least one resolved reference inside xchain-e2e-test (test code
requires it), so none is removable and nothing is deleted.
